Cuatro Modos de Escritura y Previsualización en Vivo

Tanto si prefieres editar código fuente Markdown puro, escribir sobre un lienzo híbrido sin distracciones o comparar el texto original junto al resultado final, Markdown Studio se adapta a tu flujo de trabajo:

Modo Híbrido Live Preview (WYSIWYG)

Los encabezados, tablas GFM, fórmulas matemáticas, tarjetas de código con botón de copiado y diagramas Mermaid se renderizan en el mismo lienzo mientras escribes, revelando las marcas Markdown y los colores de sintaxis únicamente en la línea o bloque donde está tu cursor, con ancho de hoja ajustable y atajo Ctrl + E para alternar entre código crudo y vista renderizada.

Vista Dividida con Scroll Sincronizado

Edita con la potencia de CodeMirror 6 a la izquierda mientras observas el documento maquetado en tiempo real a la derecha, con sincronización proporcional de desplazamiento línea por línea y divisor ajustable.

Editor de Código y Mesa de Lectura

Alterna con un clic entre el editor monoespaciado con números de línea y minimapa vectorial, o el modo Lectura libre de controles para revisar manuales, apuntes y especificaciones extensas.

Diseñado para Documentación Técnica: Fórmulas KaTeX, Mermaid y GFM

Los editores de texto convencionales suelen fallar al combinar notación matemática, diagramas de arquitectura y bloques de código. Markdown Studio procesa todo localmente en milisegundos:

Editor Markdown con LaTeX (KaTeX)

Escribe expresiones en línea como $E = mc^2$ o matrices y sistemas de ecuaciones en bloques $$...$$. El renderizado utiliza fuentes KaTeX alojadas localmente sin depender de CDNs externos.

Diagramas Mermaid en SVG Interactivo

Genera diagramas de flujo, secuencias, clases y estados dentro de bloques ```mermaid. Explora diagramas complejos a pantalla completa con zoom, arrastre y descarga directa en SVG o PNG.

Tablas GFM, Callouts y Notas al Pie

Soporte nativo para tablas GitHub Flavored Markdown, listas de tareas interactivas (- [x]), notas al pie enlazadas ([^1]) y bloques de alerta ([!NOTE], [!TIP], [!IMPORTANT], [!WARNING] y [!CAUTION]).

Convertir Markdown a PDF y HTML5 Autónomo

¿Necesitas entregar un informe técnico, trabajo académico o documentación de proyecto? Markdown Studio incorpora reglas de impresión y empaquetado profesional listas para usar:

  • Exportación limpia de Markdown a PDF: Pulsa Ctrl + P (o usa el menú de exportación) para obtener un PDF con colores de sintaxis de código conservados, diagramas Mermaid vectoriales nítidos, despliegue automático de bloques <details> y saltos de página inteligentes.
  • Exportación a HTML5 autónomo (Offline): Genera un único archivo .html independiente con hojas de estilo y fuentes KaTeX incrustadas en Base64 que se abre en cualquier navegador sin conexión.
  • Importación y descarga directa .md: Arrastra tus archivos .md o .txt al espacio de trabajo y descarga tus documentos en formato Markdown estándar cuando quieras.

Privacidad Total: Almacenamiento 100% Local en tu Navegador

A diferencia de las plataformas en la nube que exigen crear una cuenta y almacenan tus textos en servidores de terceros, Markdown Studio es un editor Markdown privado y sin registro. Todas tus carpetas y documentos se guardan directamente en la base de datos IndexedDB de tu propio navegador.

No incluye analíticas ocultas, píxeles de seguimiento ni telemetría. Una vez cargada la aplicación, todo el entorno —incluyendo fuentes tipográficas, resaltado de sintaxis, KaTeX y Mermaid— funciona 100% en local.

Preguntas Frecuentes (FAQ)

¿Markdown Studio es totalmente gratuito y sin registro?

Sí. Markdown Studio es 100% gratuito, de código abierto bajo licencia AGPL-3.0 y no solicita correo electrónico ni creación de cuenta. Puedes abrir el editor y empezar a escribir al instante.

¿Dónde se guardan mis documentos Markdown?

Todos tus archivos y carpetas se almacenan localmente en tu navegador mediante IndexedDB. Tus notas nunca se envían a ningún servidor y puedes descargarlas como .md, .html autónomo o PDF en cualquier momento.

¿Cómo puedo pasar un archivo Markdown con fórmulas y diagramas a PDF?

Abre tu documento en el editor, haz clic en el menú de exportación de la barra superior (o presiona Ctrl + P / Cmd + P) y selecciona Exportar a PDF / Imprimir. El motor ajusta automáticamente las ecuaciones KaTeX y los diagramas Mermaid para el papel.

¿Puedo cambiar el idioma de la interfaz entre español e inglés?

Sí. Tanto las páginas informativas como el editor cuentan con soporte nativo para español e inglés sin conexión, y puedes alternar el idioma en cualquier momento desde la barra superior.
